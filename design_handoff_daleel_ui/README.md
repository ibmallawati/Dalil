# تسليم واجهة دليل — الاتجاه المعتمد (شريطان + بوصلة + لوحة ألوان موسّعة)

> Handoff for `ibmallawati/eai`, branch **First-trial**. Nothing in this bundle
> touches `main` or any other branch.

## ما في هذه الحزمة

```
design_handoff_daleel_ui/
├─ templates/index.html      ← يستبدل templates/index.html
├─ static/style.css          ← يستبدل static/style.css
├─ static/script.js          ← يستبدل static/script.js
├─ reference/demo.html       ← معاينة تعمل بلا خادم (بيانات وردود تجريبية)
├─ reference/design.dc.html  ← ملف التصميم الأصلي (كل الشاشات والحالات)
├─ README.md                 ← هذا الملف
└─ CLAUDE_CODE_PROMPT.md     ← نص جاهز للصق في Claude Code
```

الملفات الثلاثة الأولى **جاهزة للتشغيل**، لا مخططات: نفس Flask + Jinja + CSS/JS
بلا أُطر ولا خطوة بناء (مناسب لـ 512MB على Render). `reference/design.dc.html`
هو المرجع البصري لكل الحالات، بما فيها حالات لم تُبنَ بعد في الخادم.

## التركيب — ثلاث خطوات

1. انسخ الملفات فوق القديمة:
   ```bash
   cp design_handoff_daleel_ui/templates/index.html templates/index.html
   cp design_handoff_daleel_ui/static/style.css      static/style.css
   cp design_handoff_daleel_ui/static/script.js      static/script.js
   ```
2. لا تغيير في `app.py`. العقد كما هو:
   - `POST /chat` ← `{ history, service_id, clarify_count }`
   - القالب يقرأ `{{ directory | tojson }}`
3. شغّل التطبيق. **`GET /usage` لم يُعد يُستدعى** من الواجهة (عدّاد الحصة أُزيل من
   الشاشة بطلب المالك). المسار في الخادم يبقى كما هو ولا يضر — والحدّ ما زال
   مُطبَّقاً في الخادم؛ عند 429 يُعرض نص الخادم العربي كخطأ مع «أعد المحاولة».

## ما تغيّر مقابل الواجهة القديمة

| القديم | الجديد |
| --- | --- |
| صفحة واحدة: بطل ← فهرس ← محادثة تُخفي كل شيء | ثلاثة أعمدة: **الفهرس** ثابت يميناً، المحادثة في الوسط، **السند** يساراً |
| الفهرس يختفي عند أول سؤال (`.is-chatting`) | الفهرس أثاث دائم؛ الخدمة الحالية تُبرَز فيه |
| المصدر سطر في أسفل البطاقة | شريط سند مستقل: بطاقة مرقّمة لكل مصدر + وسم حكومي/غير حكومي |
| الشعار: الحرف «د» في مربع أخضر | **بوصلة** SVG: دائرة + علامات الجهات الأربع + إبرة فيروزية |
| أخضر + ذهبي، حواف دائرية كبيرة (pill) | لوحة موسّعة (فيروزي/نيلي/عنبري/قرمزي/بنفسجي) وتدوير معتدل ٦–١٦px |
| قائمة جوال واحدة | طي/فتح لكل شريط + شريط سفلي في الجوال (اسأل · الفهرس · السند) |
| عدّاد حصة في الرأس | لا عدّاد |
| نصوص وأرقام لاتينية متفرّقة | **عربي بالكامل، والأرقام عربية-هندية** (`toArabicDigits`) |

## البنية والسلوك

### الطي والفتح
- سطح المكتب (> 960px): زر ☰ في رأس كل شريط يبدّل `index-folded` / `src-folded`
  على `#shell`. الشريط المطوي يصير شريحة رأسية بعرض `--rail-fold` (46px) تحمل
  اسمه وعدده، والنقر عليها يفتحه.
- الجوال (≤ 960px): الشريط لوحة منزلقة (`index-open` / `src-open`) مع حاجب
  (`.rail__scrim`)، ويُغلق بالحاجب أو Escape أو اختيار خدمة.
- الحالة تُحفظ في `localStorage`: `daleel-rail-index` / `daleel-rail-src`،
  وتُطبَّق في سكربت `<head>` قبل أول رسم (مثل السمة `daleel-theme`).

### شريط السند
يُعبَّأ من `data.sources[]` بعد كل رد:
`{ url, authority, service, title, quote? }`. البطاقة تعرض الرقم، الجهة،
اسم الخدمة، المقتطف (إن وُجد)، وسم `gov.om` أو غيره، ورابط «افتح المصدر».
الحالة أسفل الشريط هي `data.confidence` نفسها (`معلومات مؤكدة` / `معلومات جزئية`).

**نقطة تكامل واحدة اختيارية:** لو أضاف الخادم حقل `quote` (أو `snippet`) لكل
مصدر — الجملة الحرفية التي بُني عليها الرقم — ظهر الاقتباس في البطاقة تلقائياً.
بدونه تُعرض عنوان المصدر. لم أختلق نسبة تغطية ولا أرقام استشهاد لكل عبارة: لا
يوجد في العقد الحالي ما يسندها، والتصميم في `reference/design.dc.html` يوضح
كيف تظهر إن أضفتها لاحقاً (حقل `coverage` ورقم استشهاد داخل النص).

### الحالات المنفَّذة
`answer` / `card` → بطاقة + مسار تنقّل + مصادر مرقّمة · `clarify` → أزرار خيارات
(نفس عقد `service_id`) · `refusal` → لوح قرمزي · فشل الشبكة/429/500 → لوح خطأ
مع «أعد المحاولة» يعيد نفس `history` دون تكرار الدور · الانتظار → ثلاث مراحل
لفظية (لا نسبة مئوية).

## الوصولية (WCAG 2.2 AA)
كل الأزواج اللونية ≥ 4.5:1 للنص العادي · `:focus-visible` بحلقة فيروزية 2px
على كل عنصر تفاعلي · أهداف اللمس ≥ 44px في الجوال · `aria-expanded` على أزرار
الطي وبطاقات الجهات، `aria-live` على المحادثة، `aria-busy` أثناء الطلب ·
`prefers-reduced-motion` يلغي كشف النص التدريجي والحركات · رابط تخطٍّ إلى مربع
السؤال · RTL كامل بخصائص منطقية (`inset-inline`, `border-inline-start`).

## اختبار سريع بلا خادم
افتح `reference/demo.html` في المتصفح. فيه فهرس تجريبي وبديل لـ `fetch` يردّ
إجابة كاملة، ويردّ `clarify` إذا كتبت «رخصة»، و`refusal` إذا كتبت «تصريح حفر».
البديل موجود في ملف المعاينة فقط ولا يُنسخ إلى المشروع.

## ما لم يُنفَّذ في الخادم بعد (موجود في التصميم)
- `quote` / `snippet` لكل مصدر (اقتباس حرفي في بطاقة السند).
- `coverage` كنسبة عبارات مسنَدة + أرقام استشهاد داخل النص.
- بطاقة الخدمة القابلة للمشاركة والطباعة (اتجاه 1c في ملف التصميم).
