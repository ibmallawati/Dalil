# NOTE: sentence-transformers is deliberately ABSENT.
#
# Embeddings now go over HTTPS to the same OpenAI-compatible endpoint used
# for generation (see chatbot.rag.retrieval), so `openai` above covers them
# and there is no second credential.
#
# Measured on 23 Aug 2026, which is why:
#
#   app with the index loaded, no model ......    87 MB
#   after e5-base loads ......................   792 MB
#   peak while embedding one question ........ 1,143 MB
#
# sentence-transformers itself is only 4 MB, but it pulls torch (494 MB),
# transformers, scipy and sklearn — about 750 MB of install — and then
# downloads 1.1 GB of weights at runtime. Free hosts offer 512 MB.
#
# To run embeddings in-process again (EMBED_BACKEND=local), install it
# explicitly:  pip install sentence-transformers
