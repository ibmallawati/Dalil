# ============================================================================
#  DALEEL — قائمة الروابط المراد استخراجها
#  URL list for scripts/scrape_corpus.py
# ============================================================================
#
#  ADD ONE URL PER LINE. Then run:
#
#      .\venv\Scripts\python.exe scripts/scrape_corpus.py
#
#  (the script reads THIS file by default — no argument needed)
#
#  Lines starting with # are ignored. Blank lines are ignored.
#
# ---------------------------------------------------------------------------
#  ONE PAGE, SEVERAL SERVICES
# ---------------------------------------------------------------------------
#  Some pages describe more than one service. The ROP civil-status page
#  covers new ID, ID renewal AND resident card on a single URL.
#
#  Do NOT expect the scraper to split them. List the URL once per service
#  and name the service after a pipe:
#
#      https://www.rop.gov.om/arabic/e_id.aspx | إصدار البطاقة الشخصية لأول مرة
#      https://www.rop.gov.om/arabic/e_id.aspx | تجديد البطاقة الشخصية
#
#  The hint tells the model which service to extract and keeps the two
#  output files from colliding.
#
# ---------------------------------------------------------------------------
#  WHAT HAPPENS TO EACH URL
# ---------------------------------------------------------------------------
#    1. the site's robots.txt is checked   -> blocked URLs are skipped
#    2. the page is fetched, raw text saved to data/scraped_raw/
#    3. an LLM restructures it into ## sections
#    4. the VALIDATOR checks every number and document against the raw text
#    5. PASS -> data/source_docs/     FAIL -> data/needs_review/
#
#  A file that fails validation NEVER reaches data/source_docs/.
#
# ---------------------------------------------------------------------------
#  RULES
# ---------------------------------------------------------------------------
#  - Prefer .gov.om. Non-government sources are allowed but the answer card
#    will visibly flag them as «مصدر غير حكومي».
#  - Never add aggregator sites (omaneportal.com, omanpedia.net,
#    wikioman.org, ...). They look official and are not.
#  - business.gov.om publishes "Disallow: /" and WILL be skipped. That is
#    deliberate; do not try to work around it.
#  - An existing file in data/source_docs/ is never overwritten unless you
#    pass --force. Hand-written files win by default.
#
# ============================================================================
